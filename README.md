# FLORA · Rēķini

Персональный генератор счетов (rēķins) для латвийского самозанятого. Работает в браузере; профиль, клиенты, черновик и архив PDF синхронизируются между устройствами через Cloudflare.

## Как пользоваться
Откройте опубликованную ссылку сайта. Рабочая область автоматически создаётся в ссылке, а затем все устройства используют одну и ту же ссылку. Выбери клиента, впиши данные → счёт готов справа. Кнопки:
- **💾 Скачать PDF** — сохраняет готовый PDF-файл.
- **⤓ XML (e-rēķins)** — структурированный файл (черновик EN 16931 / Peppol BIS 3.0) под будущий мандат 2028.
- **🖨 Печать** — печать / «Сохранить как PDF» через браузер.
- **Новый счёт** — двигает номер на следующий.

## Что внутри
- `index.html` — само приложение (форма + живой A4-предпросмотр).
- `docs/strategy.md` — разбор рынка и стратегия (28 агентов исследования).
- `docs/template-spec.md` — спецификация шаблона счёта.

## Облако и архив

Инструкция для одноразовой настройки Cloudflare находится в `CLOUDFLARE_SETUP.md`. В обычном использовании пароль и кнопка подключения не нужны: достаточно открыть сохранённую ссылку. Доступны OCR реквизитов по фото, удаление клиента с двойным подтверждением, несколько услуг в одном счёте, импорт PDF с сохранением оригинала и архив PDF с деталями. Загруженный PDF используется как оригинал, исправленная версия создаётся по шаблону FLORA.

## Юридический контекст (Латвия)
- Обычный PDF полностью законен для B2B до 31.12.2027.
- С 01.01.2028 — обязателен структурированный e-rēķins (XML) для счетов юрлицам. Модель данных уже заложена под этот стандарт.
- Не плательщик PVN → поля PVN стоят прочерком.

⚠️ Сумма прописью на латышском и XML — рабочие черновики, перед публичным использованием нужна проверка носителем языка и валидатором Peppol.
