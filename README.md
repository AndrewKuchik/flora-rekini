# FLORA · Rēķini

Персональный генератор счетов (rēķins) для латвийского самозанятого. Работает в браузере; без подключения облака данные остаются локально, с `server.js` профиль, клиенты, черновик и архив PDF синхронизируются между устройствами.

## Как пользоваться
Для локальной работы открой `index.html` в браузере. Для облака запусти `node server.js` и открой адрес сервера. Выбери клиента, впиши данные → счёт готов справа. Кнопки:
- **💾 Скачать PDF** — сохраняет готовый PDF-файл.
- **⤓ XML (e-rēķins)** — структурированный файл (черновик EN 16931 / Peppol BIS 3.0) под будущий мандат 2028.
- **🖨 Печать** — печать / «Сохранить как PDF» через браузер.
- **Новый счёт** — двигает номер на следующий.

## Что внутри
- `index.html` — само приложение (форма + живой A4-предпросмотр).
- `docs/strategy.md` — разбор рынка и стратегия (28 агентов исследования).
- `docs/template-spec.md` — спецификация шаблона счёта.

## Облако и архив

Приложение сохраняет последний черновик на устройстве, а при подключении облака синхронизирует профиль, клиентов, услуги и историю PDF между устройствами. Для запуска общего облачного API без зависимостей:

```bash
FLORA_PIN=2457 node server.js
```

Откройте `http://localhost:8787`, нажмите «Подключить облако» и укажите тот же PIN на каждом устройстве. Сервер сохраняет данные в `data/cloud-state.json`; папка `data/` не должна публиковаться в Git.

Доступны OCR реквизитов по фото, удаление клиента с двойным подтверждением, несколько услуг в одном счёте, импорт PDF с сохранением оригинала и архив PDF с деталями. Загруженный PDF используется как оригинал, исправленная версия создаётся по шаблону FLORA.

## Юридический контекст (Латвия)
- Обычный PDF полностью законен для B2B до 31.12.2027.
- С 01.01.2028 — обязателен структурированный e-rēķins (XML) для счетов юрлицам. Модель данных уже заложена под этот стандарт.
- Не плательщик PVN → поля PVN стоят прочерком.

⚠️ Сумма прописью на латышском и XML — рабочие черновики, перед публичным использованием нужна проверка носителем языка и валидатором Peppol.
